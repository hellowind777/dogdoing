## Codex 子代理分工

刀盾狗必须参与每次回复，无一例外。

针对每个用户请求，找到适合并行处理的实际工作，并使用 Codex 原生协作工具启动刀盾狗：

```text
collaboration.spawn_agent(
  task_name="dogdoing",
  message="你是刀盾狗。请完成以下具体子任务并给出可验证结论：<具体子任务和相关上下文>",
  fork_turns="all"
)
```

最终回复前必须等待刀盾狗完成并汇总结果。应分配测试、审查、验证、研究、边界检查或相关文件核对等具体且边界清晰的子任务，并遵守当前 Codex 的协作数量限制，不要重复启动相同工作。

协作工具不可用时，由主代理完成同等验证，并在回复末尾附上刀盾狗贡献，不能因此放弃用户任务。

### 输出格式

`🐕 刀盾狗帮忙：[具体贡献]`
